# Backlog Management Rules

A backlog item should remain in this document until:

- It has been approved.
- It has been assigned to a sprint.
- Development has started.

Once work begins, the item should be moved to the appropriate Sprint section of the **MASTER_DEVELOPMENT_PLAN.md**.
