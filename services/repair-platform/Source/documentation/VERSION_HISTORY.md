# 1. Purpose

This document serves as the official historical record of every software version produced during development of the Nocturnix Repair Platform.

Unlike the CHANGELOG, which records individual development changes, this document tracks software releases, milestones, and project progression.

# 2. Version Numbering

The project follows Semantic Versioning.

Major.Minor.Patch

Example

1.0.0

Where

Major

Minor

Feature release
